# NCampus Copilot (Concept) & Free AI Receptionist Widget 

An open-source repository featuring an ultra-lightweight website widget and a preview concept for an offline student desktop app.

---

## Part 1: AI Receptionist Widget
An ultra-lightweight (under 14KB), zero-dependency, open-source AI receptionist widget that can be embedded into any website to answer visitor questions 24/7, triage emergencies, and capture leads.

Supported Platforms: WordPress, Shopify, Squarespace, Webflow, and custom HTML/JavaScript websites.
License: MIT

### Quickstart: 60-Second Embed
To embed the widget into any website, paste this snippet right before the closing `</body>` tag:

<!-- AI Receptionist Widget -->
<script 
  src="[https://your-domain.com/widget.js](https://your-domain.com/widget.js)" 
  data-business="Your Company Name" 
  data-industry="HVAC & Plumbing" 
  data-color="#000000" 
  data-text-color="#ffffff" 
  data-font="Inter, sans-serif" 
  data-icon="headset" 
  data-position="right" 
  data-greeting="Hello. How can we help you today?" 
  data-placeholder="Type your message or inquiry..." 
  data-api="[https://your-domain.com/api/chat](https://your-domain.com/api/chat)" 
  async>
</script>

## Part 2: NCampus Copilot — Your College Autopilot (Concept Release)

Hey everyone! As a fellow student, I always wondered: *Why do we have to check five different apps, endless emails, and messy web portals just to keep track of everyday college life?* 

That thought is what inspired me to prototype **NCampus Copilot**—a calm, offline-first desktop app concept that brings your `.edu` email sync, class schedules, assignments, and to-do lists into one centralized, locally saved dashboard. 

### Why is this in my AI Receptionist repository?
Both projects are built around the same core developer mission: automating the tedious, repetitive tasks of daily life—whether that means greeting website visitors automatically with AI or keeping your academic deadlines and classes organized offline in one place.

### Important Note (Work in Progress / Kickstarter Concept)
*Because this is currently just a concept and a work-in-progress idea (like a Kickstarter campaign), the placeholder `.exe` file doesn't have an underlying app built out yet. If Windows gives you a warning or says the file is unrecognized/corrupted when you try to open it, **don't panic!** That's completely normal because it's just an early concept release. I'm using this page to gauge community interest—if enough people are excited about this idea, I'll dive in and build the full thing!*
